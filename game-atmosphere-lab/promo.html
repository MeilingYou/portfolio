// Features

Everything in one place

An interactive learning tool that connects visual design theory to game atmosphere.

🎮

Game Atmosphere Lessons

Learn how art style, color, fonts, and sound change the mood of a game world.

🎨

Color Palette Viewer

Each topic includes colors that match the atmosphere and explain the visual style.

🔊

Atmosphere Sounds

Audio helps users connect sound design to visual mood.

🧪

Interactive Lab

Upload an image and apply palettes or visual effects to see mood changes.

📱

Installable PWA

The app includes a manifest and service worker so supported browsers can install it.

📁

JSON Dataset

The topics are stored in a JSON file, making it easier to add new learning sets.

// Install

How to download the PWA

Open this page or the app page in Chrome or Microsoft Edge. When the PWA passes the browser's install check, the install icon appears in the address bar.

Important: This page does not force a custom install popup. The browser install icon appears automatically when the manifest and service worker are valid.

01

Open the live GitHub Pages site

Use the deployed website link, not the GitHub repository code page.

02

Look at the address bar

Chrome or Edge should show an install icon on the right side of the address bar.

03

Click Install

Click the browser install icon, then choose Install when the browser popup appears.

04

Launch the app

After installation, open Game Atmosphere Lab like a normal app.
