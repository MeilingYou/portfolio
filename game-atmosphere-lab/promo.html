// Features

Everything in one place

An interactive learning tool that connects visual design theory to real games you know.

🎮

Game Atmosphere Lessons

Learn how art style, color, fonts, and sound change the mood of a game world.

🎨

Color Palette Viewer

Each topic includes colors that match the atmosphere and help explain the visual style.

🔊

Atmosphere Sounds

Each category includes audio so users can connect sound design to visual mood.

🧪

Interactive Lab

Upload an image and apply different palettes and visual effects to see mood changes.

📱

Installable PWA

The app includes a manifest and service worker so it can be installed on supported devices.

📁

JSON Dataset

The topics are stored in a JSON file, making it easier to add or replace learning sets.

// Install

Take it with you

Install as a PWA for easier access on supported devices.

01

Open in Chrome or Edge

The install feature works best in Chrome or Edge on desktop and Android. Safari on iPhone uses Share → Add to Home Screen instead.

02

Click Install App

An Install App button will appear on this page once your browser confirms the app is ready to install.

03

Use Browser Menu

If no button appears, open the browser menu (⋮) and choose "Install app" or "Add to Home Screen."

04

Launch Offline

Once installed, open Game Atmosphere Lab from your desktop or home screen and use it even without internet.
