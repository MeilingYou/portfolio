// Install

Take it with you

Install as a PWA for instant offline access on any device.

01

Open in Browser

Visit the app in Chrome (Android/Desktop) or Safari (iOS).

02

Find Install Prompt

Chrome: tap menu (⋮) → "Add to Home Screen". Safari: tap Share → "Add to Home Screen".

03

Confirm

Tap "Add" or "Install". The icon will appear on your home screen.

04

Use Offline

All content is cached after the first visit — no internet needed.
