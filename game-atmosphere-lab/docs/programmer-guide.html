// Programmer Guide

How to extend Game Atmosphere Lab

Everything a developer needs to modify the JSON, add new topics, and maintain the project.

01 // Project Structure

game-atmosphere-lab/
├── index.html         // Main app page
├── style.css          // All styles and font themes
├── script.js          // App logic, JSON loading, audio
├── data.json          // All topic data — edit this to add topics
├── manifest.json      // PWA manifest
├── service-worker.js  // Offline caching
├── icons/
│   ├── icon-192.png
│   └── icon-512.png
├── images/
│   └── // One PNG per topic
└── audio/
    └── // One MP3 per topic

02 // How the App Works

When the app loads, script.js fetches data.json and reads the topics array. For each topic it creates a menu button. When a button is clicked, the page updates its text, image, CSS variables, font class, and audio — all from the JSON data. No HTML or JS changes are ever needed to add a new topic.

03 // JSON Field Reference

Each object in the topics array supports these fields:

FieldTypeDescription
id requiredstringUnique kebab-case slug used in the URL hash. No spaces or capitals. E.g. neon-cyberpunk-city
title requiredstringDisplay name shown as the heading and menu button label.
gameExamples requiredstring[]Array of real game titles that use this atmosphere style.
artStyle requiredstringShort description of the visual design style.
mood requiredstringComma-separated mood words.
description requiredstringEducational paragraph explaining why this style creates its mood.
backgroundColor requiredhexPage background color for this atmosphere.
accentColor requiredhexUsed for headings, button borders, and highlights.
textColor requiredhexMain body text — ensure contrast with backgroundColor.
fontClass requiredstringCSS class applied to <body>. Must match a class in style.css.
image requiredstringRelative path to the image. E.g. images/my-topic.png
imageAltstringAccessible alt text for the image. Recommended.
audio requiredstringRelative path to the MP3 file. E.g. audio/my-topic.mp3

04 // Adding a New Topic

01

Add your files

Place your image in images/ and audio in audio/. Use kebab-case naming — e.g. isometric-city.png and isometric-city.mp3.

02

Add a font class if needed

If using a new font, add it to the Google Fonts link in index.html and add a class at the bottom of style.css:

.my-font-class {
  font-family: "Your Font", sans-serif;
}
03

Add the topic object to data.json

Open data.json and add a new object inside the topics array. Separate it from the previous entry with a comma.

{
  "id": "isometric-city",
  "title": "Isometric City",
  "gameExamples": ["Cities: Skylines", "SimCity"],
  "artStyle": "Top-down isometric urban style",
  "mood": "Strategic, busy, satisfying",
  "description": "Isometric city games use a top-down angle...",
  "backgroundColor": "#2C3E50",
  "accentColor": "#3498DB",
  "textColor": "#ECF0F1",
  "fontClass": "my-font-class",
  "image": "images/isometric-city.png",
  "imageAlt": "A colorful isometric city grid",
  "audio": "audio/isometric-city.mp3"
}
04

Update the service worker cache

Open service-worker.js, add the new file paths to ASSETS_TO_CACHE, and bump the cache version number.

const CACHE_NAME = "game-atmosphere-lab-v2"; // increment version

// Add these to ASSETS_TO_CACHE:
"/portfolio/game-atmosphere-lab/images/isometric-city.png",
"/portfolio/game-atmosphere-lab/audio/isometric-city.mp3",
✅ Done

Refresh the app — your new topic button will appear in the menu automatically. No HTML or JS changes needed.

05 // Common Mistakes

  • Missing comma in JSON — every topic except the last must end with a comma. Validate at jsonlint.com.
  • Wrong file path — paths are relative to index.html. Always use images/filename.png, not just filename.png.
  • fontClass mismatch — the JSON value must exactly match the CSS class name including hyphens.
  • Forgetting to update the service worker — new files won't be available offline unless added to ASSETS_TO_CACHE and the cache version is bumped.
  • Case sensitivity — file names on GitHub Pages are case-sensitive. Dark-Fantasy.png and dark-fantasy.png are different files.
