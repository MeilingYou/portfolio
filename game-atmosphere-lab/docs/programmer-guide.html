Project Structure

Here is the complete file structure of the project:

game-atmosphere-lab/
├── index.html         // Main app page
├── style.css          // All styles and font themes
├── script.js          // App logic, JSON loading, audio
├── data.json          // All topic data (edit this to add topics)
├── manifest.json      // PWA manifest
├── service-worker.js  // Offline caching
├── icons/
│   ├── icon-192.png   // PWA icon (192x192)
│   └── icon-512.png   // PWA icon (512x512)
├── images/
│   └── // One PNG per topic
└── audio/
    └── // One MP3 per topic

How the App Works

When the app loads, script.js fetches data.json and reads the topics array. For each topic it:

  • Creates a button in the atmosphere menu
  • When clicked, updates the page text, image, colors, font class, and audio
  • Reads URL hash on load so bookmarked atmospheres open correctly

All topic data lives in data.json — the HTML and JS never need to be edited when adding new topics.

The JSON File (data.json)

This is where all topic content is stored. The file contains one array called topics, and each item in the array is one atmosphere.

Full Topic Object Example

{
  "id": "neon-cyberpunk-city",
  "title": "Neon Cyberpunk City",
  "gameExamples": ["Cyberpunk 2077", "Ghostrunner"],
  "artStyle": "Neon sci-fi and futuristic city style",
  "mood": "Futuristic, energetic, high-tech",
  "description": "Cyberpunk games use dark backgrounds and neon lights...",
  "backgroundColor": "#0D0B1F",
  "accentColor": "#00E5FF",
  "textColor": "#EAFBFF",
  "fontClass": "cyberpunk",
  "image": "images/neon-cyberpunk-city.png",
  "imageAlt": "A rainy futuristic city lit by neon signs",
  "audio": "audio/neon-cyberpunk-city.mp3"
}

Field Reference

Field Type Description
id required string Unique kebab-case identifier. Used in the URL hash (e.g. #neon-cyberpunk-city). No spaces or capital letters.
title required string Display name shown as the heading and menu button label.
gameExamples required array of strings List of real game titles that use this atmosphere style.
artStyle required string Short description of the visual design style.
mood required string Comma-separated mood words (e.g. "Peaceful, warm, relaxing").
description required string Educational paragraph explaining why this style creates its mood.
backgroundColor required hex color Page background color for this atmosphere (e.g. #0D0B1F).
accentColor required hex color Used for headings, button borders, and highlights.
textColor required hex color Main body text color — make sure it contrasts with backgroundColor.
fontClass required string CSS class applied to <body> to change the font. Must match a class defined in style.css.
image required string (path) Relative path to the atmosphere image (e.g. images/my-topic.png).
imageAlt string Accessible alt text for the image. Recommended for accessibility.
audio required string (path) Relative path to the MP3 audio file (e.g. audio/my-topic.mp3).

How to Add a New Topic

Step 1 — Prepare your files

  • Add your image to the images/ folder (PNG recommended, any size)
  • Add your audio to the audio/ folder (MP3 format)
  • Use consistent kebab-case naming: e.g. isometric-city.png and isometric-city.mp3

Step 2 — Add a CSS font class (if using a new font)

Open style.css and add a new class at the bottom of the font themes section:

.my-new-fontclass {
  font-family: "Your Font Name", sans-serif;
}

Also add the font import to index.html in the Google Fonts <link> tag.

Step 3 — Add the topic to data.json

Open data.json and add a new object inside the topics array. Separate it from the previous item with a comma:

{
  "id": "isometric-city",
  "title": "Isometric City",
  "gameExamples": ["Cities: Skylines", "SimCity"],
  "artStyle": "Top-down isometric urban style",
  "mood": "Strategic, busy, satisfying",
  "description": "Isometric city games use a top-down angle...",
  "backgroundColor": "#2C3E50",
  "accentColor": "#3498DB",
  "textColor": "#ECF0F1",
  "fontClass": "my-new-fontclass",
  "image": "images/isometric-city.png",
  "imageAlt": "A colorful isometric city grid",
  "audio": "audio/isometric-city.mp3"
}

Step 4 — Update the service worker cache list

Open service-worker.js and add the new image and audio paths to the ASSETS_TO_CACHE array so they work offline:

"/portfolio/game-atmosphere-lab/images/isometric-city.png",
"/portfolio/game-atmosphere-lab/audio/isometric-city.mp3",

Also bump the cache version at the top of the file so the service worker refreshes:

const CACHE_NAME = "game-atmosphere-lab-v2"; // increment version number
✅ DONE Refresh the app and your new topic button will appear automatically in the menu — no HTML or JS changes needed.

Common Mistakes

  • Missing comma in JSON — every topic object except the last one must end with a comma. Use a JSON validator like jsonlint.com to check.
  • Wrong file path — paths in JSON are relative to index.html. Always use images/filename.png not just filename.png.
  • fontClass doesn't match CSS — the value in JSON must exactly match the CSS class name including hyphens.
  • Forgot to update service worker — new files won't load offline unless added to ASSETS_TO_CACHE.
