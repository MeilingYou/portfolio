WickEditor Animation Project

This animation was created in WickEditor. The scene uses a background layer, middle layer, and foreground layer. It is set to 30 frames per second and is longer than 3 seconds.

Scene Description

This is a snowy winter road scene. The background layer contains the moon, night sky, mountains, and snow field. The middle layer contains pine trees and a forest. The foreground layer contains the road, falling snow, and a red car moving across the screen. Tweens were used to create smooth movement.

Animation Video

The video is set to loop so the animation repeats automatically.
